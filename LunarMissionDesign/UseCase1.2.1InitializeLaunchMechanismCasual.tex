\textbf{Initialize Launch Mechanism--Casual Format}\\
\textit{Main Success Scenario}
\begin{enumerate}
\item With the System running, the Flight Director enter the Mission
Parameters File (See \textit{Use Case 1 Initialize Launch})
\item System opens the Mission Parameters File
\item System finds the Launch Platform Data
\item System finds the Launch Mechanism Data in the Launch Platform
Data
\item System stores the Launch Mechanism Data
\item System finds the Rocket Data
\item System stores the needed Rocket Data
\item System returns the Initialized Launch Mechanism Data to the
Flight Director
\end{enumerate}
\textit{Alternative Scenarios}
\begin{itemize}
\item[2a.]If the System cannot open the Mission Parameters File, then
the System alerts the Flight Director of the Error.
\item[3a.]If the System cannot access the Launch Platform Data, then
the System alerts the Flight Director of the Error.
\item[4a.]If the System cannot access the Launch Mechanism Data, then
the System alerts the Flight Director of the Error.
\item[6a.,7a.]If there is no Rocket Data available, then the System
continues without storage, alerting the Flight Director
\end{itemize}
\textit{Notes/Constraints}
\begin{itemize}
\item[6b.,7b.]Since prior Rocket Initializations is a definite
possibility at this point, the more likely scenario is the System
accesses the initialized Rocket Data
\end{itemize}
