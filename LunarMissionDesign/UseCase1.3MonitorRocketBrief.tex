\textbf{Monitor Rocket--Brief Format}
\begin{enumerate}
   \item Flight Director Initializes Rocket via inputing the Mission
      Parameters File (See \textit{Use Case 1.1 Initialize Rocket})
   \item For each Stage, System periodically Monitors the Stage (See
      \textit{Use Case 1.3.1 Monitor Stage})
   \item System returns the monitored Stage Data to to the Flight
      Director
   \item System periodically monitors the Payload/Capsule (See
      \textit{Use Case 1.3.2 Monitor Capsule})
   \item System returns the monitored Payload/Capsule Data to the
      Flight Director
\end{enumerate}
