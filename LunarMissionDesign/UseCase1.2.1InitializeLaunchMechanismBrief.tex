\textbf{Initialize Launch Mechanism--Brief Format}
\begin{enumerate}
   \item Flight Director enters the Mission Paramenters File (See
      \textit{Use Case 1 Initialize Launch})
   \item System opens the Mission Parameters File
   \item System finds the Launch Platform Data
   \item System finds the Launch Mechanism Data in the Launch
      Platform Data
   \item System stores the Launch Mechanism Data
   \item System finds the Rocket Data
   \item System stores the Rocket Data pertinent to the Launch
      Mechanism
   \item System returns Launch Mechanism Data to the Flight Director
\end{enumerate}
