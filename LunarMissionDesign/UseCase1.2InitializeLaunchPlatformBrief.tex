\textbf{Initialize Launch Platform--Brief Format}
\begin{enumerate}
   \item Flight Director Enters the Mission Parameters File (See
      \textit{Use Case 1 Initialize Launch})
   \item System opens the Mission Parameters File
   \item System finds the Launch Mechanism (Platform) Data
   \item System stores the Launch Mechanism (Platform) Data
   \item For each hold on the Launch Mechanism (Platform), System
      initializes the hold (See \textit{Use Case 1.3 Initialize 
      Launch Mechanism})
   \item System finds the Rocket Data
   \item System stores the Initial Rocket Data needed
   \item System returns the Initialized Launch Mechanism Data to the
      Flight Director
   \item System returns the Rocket Data to the Flight Director
\end{enumerate}
